# 型号匹配与真伪判读（matching-rules）

## 1. 内存型号解码（三星 DDR4 UDIMM）

命名结构：`M378A{density}{die}43{rev}-{bin}`

| 型号片段 | 标称容量 | 典型组织 | 说明 |
|---|---|---|---|
| `M378A1G43` | **8GB** | 2Rx8（16 × 4Gb） | 例：M378A1G43EB1-CPB（2133）/ -CWE（3200） |
| `M378A2K43` | **16GB** | 2Rx8（16 × 8Gb） | 例：M378A2K43CB1-CWE |
| `M378A2G43` | **16GB** | 1Rx8（8 × 16Gb） | 单面 16GB |
| `M378A4K43` | **32GB** | 2Rx8 | — |
| `M378A4G43` | **32GB** | 1Rx8 | — |

> `G` / `K` 主要反映颗粒代际与单颗密度（16Gb vs 8Gb），进而决定 rank 数；**不要只看字母猜 rank，最终以 SPD 的 Module Organization 字节为准**。

DDR5 是另一套命名（`M323...`），不要套用本表。

## 2. 改标条判定

系统能读到两组互相独立的事实：

1. **型号字符串**（SPD 里人写的）
2. **容量 / rank / 颗粒密度**（SPD 里按物理颗粒编码的）

原厂出厂时两者必然一致。出现下面任一组合，判「SPD 被改写过」：

| 型号说 | 实际读到 | 结论 |
|---|---|---|
| 8GB / 2R | 16GB / 1R | 容量与组织都不符 → 改标 |
| 8GB / 2R | 16GB / 2R | 容量不符 → 改标或标签错 |
| 16GB / 2R | 16GB / 2R | 一致 |
| 型号为空 / 乱码 | 任意 | 非零售正品可能性高 |

**改标条 ≠ 一定坏**，但意味着：来源不明、无保修、SPD 参数可能被改过（频率/时序可能是刷上去的）。稳定性排查时优先替换。

## 3. 频率与超频判定

| 组合 | 判定 |
|---|---|
| `Speed = ConfiguredClockSpeed`，电压 1.2V | 标准 JEDEC，未超频 |
| 实际 < 额定 | 被降频（混插保护 / 主板限制） |
| 电压 > 1.25V | 开了 XMP/EXPO 或手动调压 |
| 有 XMP/EXPO 配置表 | 支持超频，未必已启用 |

> BIOS 里是否真的开了 XMP，软件层读不到「设置项」，只能从**实际频率 + 电压**推断。

## 4. 混插判定

| 情况 | 风险 |
|---|---|
| 同型号同频率 | 低 |
| 同容量不同型号 | 中（时序/颗粒不同） |
| 不同容量 | 中（非对称双通道） |
| 不同频率 | 高（按低频跑，可能训练失败） |
| 单 rank + 双 rank 混插 | 中高（部分主板/BIOS 训练不稳） |

建议：**同型号成对**；不稳时先把频率降到 2933 或关 XMP 观察。

## 5. CPU / 主板匹配

| 检查 | 方法 |
|---|---|
| 插槽 | `Win32_Processor.SocketDesignation` 与主板规格对比 |
| 芯片组支持 | 主板官网 CPU 支持列表（需联网） |
| BIOS 是否支持该 CPU | 主板官网 + 当前 BIOS 版本 |
| 供电 | 高端 CPU + 入门主板要查 VRM 与供电接口 |

常见桌面插槽：Intel LGA1700（12/13/14 代）、LGA1851（Core Ultra 200S）、AMD AM4 / AM5。
**不要凭 CPU 名称直接断言兼容，必须查主板支持列表。**

## 6. 显卡 / 电源匹配

软件读不到 PSU 型号与功率，只能给「需求侧」估算：

```
建议电源额定功率 ≈ GPU TDP + CPU TDP + 150~200W 余量
```

| GPU | 典型 TDP |
|---|---|
| RTX 4060 | 115W |
| RTX 3060 | 170W |
| RTX 4070 | 200W |
| RTX 3070 | 220W |
| RTX 3080 / 4080 | 320W |
| RTX 4090 | 450W |

其他检查：显卡长度 vs 机箱、供电接口（8pin × 几个）、是否需要转接线。

**结论里必须写**：`PSU 型号/功率：UNKNOWN（软件不可读）`。

## 7. 存储接口匹配

| 检查 | 说明 |
|---|---|
| 系统盘接口 | NVMe > SATA SSD > HDD |
| NVMe 代数 | PCIe 3.0/4.0/5.0 与主板插槽匹配 |
| M.2 长度 | 2280 / 2242 / 2230 |
| SATA 口剩余 | 加盘前确认 |
| 剩余空间 | 系统盘 ≥15%，数据盘 ≥10% |

## 8. 显示器 EDID

`WmiMonitorID` 可读到厂商代码（如 `GSM` = LG）、型号名、序列号、生产年周。
读不到就写 UNKNOWN；**不要用分辨率推断面板型号**。

## 9. 劣质/异常硬件信号清单

- 内存：型号与容量/rank 不符、无厂商名、序列号异常、混插不同批次
- SSD：无品牌、SMART 全 0、固件版本异常、磨损与通电时长明显不匹配
- 显卡：显存容量与型号不符（改卡）、驱动装不上、频繁 TDR
- 电源：无法读取（正常）、但若 41 事件集中在高负载时 → 重点怀疑
- 主板：厂商/型号为空、序列号 `System Serial Number`（常见于白牌/工程板）
- USB：VID/PID 为 `0000:0000`、频繁 51/157

## 10. 边界

- 容量、频率、电压、rank、SMART 可读
- **颗粒真伪、是否矿卡、是否翻新，软件无法判定**，只能给「可疑」不给「确定」
- 价格、渠道、保修政策不在本技能范围

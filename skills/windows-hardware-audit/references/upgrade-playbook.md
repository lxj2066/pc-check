# 升级与换件决策树（upgrade-playbook）

## 0. 顺序铁律

**先修 P0（数据风险）→ 再修 P1（稳定性）→ 最后谈 P2/P3（性能）。**

硬件不稳定时做性能升级，等于在漏水的船上装帆。

## 1. 视频渲染 / 剪辑（profile=video）

| 瓶颈信号 | 优先升级 | 兼容性检查 |
|---|---|---|
| 内存 < 32GB、时间线卡顿、换页频繁 | 内存 → 32/64GB | 槽位、DDR4/DDR5、同型号成对 |
| 显存 < 8GB、4K 素材爆显存 | 显卡 | 电源功率、机箱长度、供电接口 |
| CPU 线程 < 12、导出慢 | CPU | 主板插槽、BIOS 支持、供电/散热 |
| 素材盘是 HDD / 剩余 <15% | NVMe | M.2 插槽代数与长度 |
| 温度 >85°C、导出降频 | 散热/风道 | 机箱风道、散热器高度 |

**视频用途的收益排序**：内存容量 ≥ 显存 > NVMe > CPU 多核 > 显卡算力。

## 2. 量化回测 / 数据处理（profile=quant）

| 瓶颈信号 | 优先升级 | 兼容性检查 |
|---|---|---|
| 内存 < 32GB、pandas 吃满 | 内存 | 同上 |
| 单核性能弱、循环慢 | CPU（看单核） | 插槽/BIOS |
| 数据盘 IO 慢 | NVMe | 插槽 |
| 线程少、并行慢 | CPU 多核 | 供电/散热 |

**注意**：量化回测常常是**单核 + 内存带宽**瓶颈，堆核心数不一定有用。

## 3. 办公 + 多开 AI 工具（profile=office）

| 瓶颈信号 | 优先升级 | 兼容性检查 |
|---|---|---|
| 内存 < 16GB、浏览器多开卡 | 内存 | 槽位 |
| 系统盘满 / HDD | SSD | SATA/M.2 |
| 开机慢、后台多 | 先清理自启（用 pc-doctor） | — |

## 4. 通用升级检查清单

### 内存
- [ ] 主板是 DDR4 还是 DDR5（不可混用）
- [ ] 空闲槽位数量
- [ ] 单条最大容量与总容量上限
- [ ] 是否要与现有条同型号（推荐）
- [ ] 是否需要更新 BIOS 才支持大容量

### 显卡
- [ ] 电源额定功率与 12V 输出
- [ ] 供电接口数量（8pin/12VHPWR）
- [ ] 机箱显卡限长
- [ ] 显示器接口（HDMI/DP 版本）
- [ ] CPU 是否会成为新瓶颈

### 存储
- [ ] M.2 插槽数量与 PCIe 代数
- [ ] M.2 长度（2280 最常见）
- [ ] SATA 口与供电线
- [ ] 是否需要迁移系统

### CPU
- [ ] 插槽一致
- [ ] 主板官网 CPU 支持列表
- [ ] BIOS 版本是否支持
- [ ] 散热器压得住新 TDP
- [ ] 供电接口与 VRM

## 5. 驱动更新

| 设备 | 来源 | 注意 |
|---|---|---|
| 显卡 | NVIDIA / AMD 官网 | 视频剪辑可选 Studio 驱动；游戏选 Game Ready |
| 芯片组 | 主板官网 | 先装芯片组，再装其他 |
| 网卡/声卡 | 主板官网或芯片厂商 | 不要用来路不明的「驱动大师」 |
| 存储固件 | 厂商官方工具 | 更新前备份 |

**流程**：记录当前版本 → 官网下载 → 卸旧（显卡可用 DDU）→ 装新 → 复测。
**不要**在排查稳定性期间同时更新多个驱动，否则无法归因。

## 6. 升级后的验证

1. 重跑 `collect.ps1` + `analyze.py`，确认型号/容量/频率识别正确
2. 跑一次内存诊断（换了内存必做）
3. 用实际工作负载跑 30 分钟，看温度与是否掉频
4. 连续观察 2–3 天，确认没有新的 41/蓝屏/磁盘错误

## 7. 明确不建议

- 不稳定时先超频/开 XMP
- 用「一键优化」「内存清理」软件
- 混插不同型号内存追求大容量
- 电源功率刚好卡在临界值
- 在没备份的情况下刷 BIOS
- 用第三方驱动包批量更新
